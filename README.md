# موقع شركة مدار الرسمي | MADAR Official Website

> **موقع بهوية سعودية تراثية معاصرة، حركة مع كل سكرول، وهدف واحد: أن يشعر الزائر من أول ثانية بأنه يريد أن يحجز.**

تم بناء هذا الموقع لشركة **مدار (Madar)** المتخصصة في مونتاج الفيديو، تصميم وتطوير المواقع والمنصات، والجرافيك ديزاين وبناء الهوية البصرية، مستهدفاً السوق السعودي والخليجي.

---

## 🌟 مميزات الموقع والتقنيات المستخدمة

- **واجهة عربية أولاً (RTL First):** دعم كامل للغة العربية والإنجليزية، مع خصائص CSS المنطقية (`margin-inline`...).
- **الهوية البصرية التراثية السعودية:**
  - ألوان معتمدة: أخضر مدار العميق (`#0E3B33`)، ذهبي (`#B8892F`)، ذهبي فاتح (`#D9AE55`)، رملي نجدي (`#F4EEE0`)، طين الدرعية (`#9A4E2E`)، أحمر السدو (`#7A2623`)، ونيلي عسير (`#1F3A5F`).
  - زخارف SVG نقية ومبرمجة داخل الكود (دون صور خارجية أو حقوق ملكية): شرفات الدرعية النجدية، أشرطة السدو الهندسية، مشربيات وروشان الحجاز، وتلوين القط العسيري.
  - أيقونات خطية متناسقة: الباب النجدي، دلة القهوة العربية مع بخار تفاعلي، والنخلة.
- **حركة سلسة ومتقدمة (Scroll Dynamics):**
  - شاشة دخول تحاكي انفتاح أبواب نجد التراثية مع رسم خطوط النجمة الثمانية وحركة دوران النقطة الذهبية.
  - سكرول ناعم عبر مكتبة **Lenis**.
  - تأثيرات ظهور تدريجي مع **GSAP 3 & ScrollTrigger**، ومسار مداري منحني تمشي عليه النقطة الذهبية في قسم المسيرة.
  - شريطان متحركان لآراء العملاء (Marquee) يتعاكسان في الاتجاه ويتوقفان عند التمرير واللمس.
- **نموذج حجز عالي التحويل:**
  - تحقق ذكي من أرقام الجوال السعودية بصيغة (`+9665XXXXXXXX` أو `05XXXXXXXX`).
  - اختيار تلقائي للخدمة المطلوبة عند النقر على بطاقات الخدمات.
  - رسالة نجاح مبهجة بروح الضيافة السعودية («أبشر بسعدك!»)، مع زر متابعة فوري عبر واتساب.
- **التوافق الكامل مع نظام حماية البيانات الشخصية السعودي (PDPL):**
  - شريط موافقة لملفات تعريف الارتباط لا يفعّل بكسلات التتبع إلا بعد موافقة الزائر.
  - نافذة منبثقة تفصيلية لسياسة الخصوصية.
- **إمكانية الوصول والأداء:**
  - احترام تفضيل تقليل الحركة (`prefers-reduced-motion`).
  - تباين ألوان يحقق معايير WCAG AAA / AA.
  - تحميل الخطوط بخاصية `font-display: swap` و `preload`.

## 🚀 كيفية تشغيل الموقع محلياً

يعمل الموقع بأمر واحد بسيط ولا يتطلب أي إعدادات معقدة:

### الطريقة الأولى: الفتح المباشر
- يمكنك ببساطة النقر المزدوج على ملف `index.html` لفتحه في أي متصفح حديث (Chrome, Safari, Edge, Firefox).

### الطريقة الثانية: عبر خادم محلي (موصى به لتجربة كاملة لـ Fetch API)
افتح الطرفية (Terminal / PowerShell) داخل مجلد المشروع ونفّذ الأمر:

```bash
# باستخدام بايثون (المثبت مسبقاً)
python -m http.server 8000
```
ثم افتح الرابط: `http://localhost:8000`

## ✏️ دليل استبدال المتغيرات والـ [Placeholders]

وفقاً لقواعد البريف الصارمة: **لا تُخترع أي بيانات أو أرقام أو أسماء غير مؤكدة.** تم وضع علامات `[Placeholder]` واضحة في الملفات.

إليك كيفية استبدالها بالبيانات الحقيقية للمنشأة:

### 1. بيانات التواصل والتوثيق التجاري (في `content.json` و `index.html`):
- `[+966 5X XXX XXXX]`: استبدله برقم واتساب وهاتف الشركة المعتمد (مثال: `+966 50 123 4567`).
- `[contact@[madar-domain]]`: استبدله بالبريد الرسمي.
- `[madar-domain]`: استبدله بالنطاق الفعلي للموقع.
- `[رقم السجل التجاري / وثيقة العمل الحر / معروف]`: استبدله برقم التوثيق الرسمي للمنشأة، ويُعرض في التذييل.
- `[Instagram, TikTok, Snapchat, X, LinkedIn]`: استبدل الروابط في أسفل التذييل بروابط حسابات الشركة على الشبكات الاجتماعية.
- `[رابط الملف التجاري على Google]`: استبدله برابط صفحة Google Business لتحقق التقييمات.

### 2. الأرقام وشريط الثقة:
- `[X] سنة`: استبدلها بالعدد الحقيقي لسنوات عمل مدار في السوق السعودي.
- `[N] مشروع`: استبدلها بالعدد الفعلي للمشاريع المنجزة.
- `[N] عميل`: استبدلها بعدد العملاء الفعليين.
- `[N]% نسبة الرضا`: استبدلها بنسبة رضا العملاء المسجلة.
*(ملاحظة: إذا لم تتوفر أرقام موثقة حتى الآن، اتركها كـ `[Placeholder]` أنيق كما هي حالياً).*

### 3. مسيرتنا وأعمالنا:
- **المسيرة (`milestones` في `content.json`):** استبدل `[سنة 1]`، `[سنة 2]`... والمحطات بالأحداث الواقعية للشركة.
- **الأعمال (`projects` في `content.json`):** استبدل أسماء المشاريع والعملاء والصور بملفات أعمال مدار الفعلية بمجرد تسليمها.

### 4. آراء العملاء (`testimonials.json`):
- يمنع منعاً باتاً تأليف أسماء أو تقييمات وهمية.
- يتم إدخال الآراء الواقعية التي وصلتكم من واتساب أو تقييمات خرائط جوجل فقط مع توفر موافقة العميل (`"consent": true`).
- يقوم الموقع بحساب متوسط التقييم وعدد المراجعات وتوليد بيانات `Schema.org (JSON-LD)` تلقائياً بناءً على هذا الملف!

### 5. ربط نموذج الحجز بنقطة استقبال فعلية:
في ملف `script.js` داخل دالة `initBookingForm`:
- يمكنك ربط الاستقبال عبر خدمة مجانية مثل [Formspree](https://formspree.io) أو Webhook إلى Google Sheets أو إرسال بريد إلكتروني مباشر.
- يمكنك تعديل رقم هاتف الواتساب في متغير `whatsappRaw: "966500000000"` ليتطابق مع رقم مسؤول المبيعات.

## ☁️ دليل نشر الموقع على الإنترنت (Deployment)

### النشر على Vercel (الأسهل والأسرع)
1. سجّل الدخول إلى [Vercel](https://vercel.com).
2. انقر على **"Add New Project"** ثم اختر مستودع Git الخاص بالمشروع، أو اسحب مجلد `madar` وأفلته في واجهة Vercel مباشرة (Deploy via Drag & Drop).
3. اختر الإعدادات الافتراضية (Static Site).
4. انقر **"Deploy"** وسيتم نشر الموقع في أقل من دقيقة مع شهادة SSL مجانية وسرعة فائقة من سيرفرات الخليج.

### النشر على Netlify
1. سجّل الدخول إلى [Netlify](https://www.netlify.com).
2. انتقل إلى تبويب **"Sites"** واسحب مجلد المشروع بالكامل وأفلته في منطقة **"Drag and drop your site output folder here"**.
3. ستحصل على رابط فوري لموقعك، ويمكنك ربط نطاقك الخاص (مثل `[madar-domain]`) بخطوات بسيطة من لوحة التحكم وإضافة سجلات DNS.

## 🔒 الامتثال لنظام حماية البيانات السعودي (PDPL)
تم تزويد الموقع بشريط موافقة لملفات تعريف الارتباط متوافق مع نظام حماية البيانات الشخصية السعودي.
- لا يتم تفعيل أي وسوم تتبع تسويقية (Google Analytics, TikTok Pixel, Snapchat Pixel, Meta Pixel) إلا بعد نقر الزائر على زر "أوافق".
- يتم حفظ موافقة الزائر محلياً في `localStorage`.
